# Proposal Proyek Kalkulator Geometri

## 1. Latar Belakang
Siswa sering mengalami kesulitan dalam menghitung
luas, keliling, dan volume bangun geometri.
Oleh karena itu, dibuat program Kalkulator
Geometri untuk mempermudah perhitungan.

## 2. Pengguna dan Tujuan
Pengguna: Siswa SMP/SMA.

Tujuan:
- Mempermudah perhitungan geometri.
- Membantu memahami rumus matematika.
- Mempercepat proses perhitungan.

## 3. Ruang Lingkup
Program menghitung persegi, persegi panjang,
segitiga, lingkaran, kubus, dan balok.

## 4. Kebutuhan
Program menerima ukuran bangun geometri,
memproses perhitungan, dan menampilkan hasil.

## 5. Input, Proses, Output
Input: Ukuran bangun geometri.
Proses: Perhitungan menggunakan rumus.
Output: Hasil luas, keliling, dan volume.

## 6. Algoritma
1. Mulai.
2. Tampilkan menu.
3. Pilih bangun geometri.
4. Masukkan ukuran.
5. Hitung hasil.
6. Simpan riwayat.
7. Tampilkan hasil.
8. Selesai.

## 7. Struktur Program
Program terdiri dari main.py, analisis.py,
data_io.py, dan utilitas.py.

## 8. Struktur Data
Menggunakan fungsi, variabel, string,
dan file teks.

## 9. Test Case
Pengujian dilakukan dengan input normal,
batas, dan invalid.
