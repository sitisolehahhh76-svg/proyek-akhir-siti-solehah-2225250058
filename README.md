Nama: Siti Solehah

Kelas: 3B

## Tujuan
Membuat program kalkulator geometri menggunakan
Python untuk menghitung luas, keliling, dan volume
bangun datar serta bangun ruang.

## Fitur
1. Menghitung luas dan keliling persegi.
2. Menghitung luas dan keliling persegi panjang.
3. Menghitung luas segitiga.
4. Menghitung luas dan keliling lingkaran.
5. Menghitung volume kubus.
6. Menghitung volume balok.
7. Menyimpan riwayat perhitungan.

## Cara Menjalankan
python src/main.py

## Struktur Program
- main.py: Program utama.
- analisis.py: Proses perhitungan geometri.
- data_io.py: Membaca dan menyimpan riwayat.
- utilitas.py: Menu dan validasi input.

## Pengujian
Pengujian dilakukan menggunakan test case
normal, batas, dan input tidak valid.
